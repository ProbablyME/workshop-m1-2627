SENTINEL-X — L'avant-poste industriel du futur

Le boîtier et son réseau

  • ESP8266 + DHT22, MQ-2, PIR, OLED, buzzer mélodique, LED bicolore, imprimé en 3D au Fablab.
  • Télémétrie toutes les 5 s en MQTT sur TLS 1.3, certificat épinglé, broker authentifié.
  • Alertes réflexe avec hystérésis ; gaz par ligne de base auto-calibrée.
  • Commandes descendantes : alarme, LED, intrusion caméra.
  • Réseau de table isolé 192.168.10.0/24, serveur = laptop (option B).

Le serveur

  • Docker Compose : Mosquitto, PostgreSQL, API FastAPI, nginx.
  • API REST + WebSocket, validation stricte, clé sur toutes les écritures.
  • Base non exposée, conteneurs sans root, secrets générés, zéro secret dans Git.
  • Dashboard React : courbes temps réel, journal, commandes, IA.

L'intelligence embarquée

  • Vision : YOLOv8n sur webcam USB, classe personne, alerte d'intrusion, flux annoté dans le dashboard.
  • Prédictif : Isolation Forest sur fenêtres de 5 min, pentes et corrélation température / gaz, ré-entraîné toutes les 30 min.
  • Aucune condition statique : le modèle apprend la normale et signale ce qui s'en écarte.

La sécurité

  • Chiffrement de bout en bout ESP → broker : TLS 1.3, AES-256-GCM, RSA 2048.
  • Broker : anonyme refusé, comptes, limites de connexions et de messages.
  • API : clé injectée par le proxy, jamais dans le navigateur ; payloads validés.
  • Dashboard : authentification, en-têtes anti-clickjacking.
  • Jeudi : port 1883 fermé, durcissement de l'hôte, pentest croisé et rapport d'audit.
